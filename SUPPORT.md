# Support

This is a community-oriented synthetic demonstration, not a supported
commercial underwriting product.

For help:

- Read the installation, execution, and troubleshooting sections in
  [README.md](README.md).
- Search existing GitHub issues before opening a new one.
- Use a GitHub issue for reproducible bugs or narrowly scoped feature requests.
- Use the private reporting process in [SECURITY.md](SECURITY.md) for security
  concerns.

When reporting a problem, include sanitized logs, Python and Kestra versions,
and the exact steps needed to reproduce it. Never include real applicant data,
credit reports, credentials, or production secrets.

No service-level agreement, production support, or guarantee of fitness for a
regulated lending use case is provided.
