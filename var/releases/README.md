# Approved production releases

Only immutable, approved production packages belong under `approved/<release-id>/`. A release is assembled from a verified DEV candidate, registered evaluation evidence, an explicit approval attestation and a digest-pinned Core task image. Assembly does not deploy the package.

See [UWflow lifecycle and storage model](../../docs/architecture/lifecycle-and-storage.md#5-approve-and-assemble-a-production-release) for the release contract and [the Production operator guide](../../modules/production/README.md) for the commands and deployment process.
